Question 1: Why do we use equals() instead of "==" when comparing student Ids. 
Answer: "==" compares memory references (whether 2 objects point to the exact same object), while "equals()"
compares object contents (whether 2 distinct objects hold the same data). "==" checks object identity while
"equals()" checks equivalence.
